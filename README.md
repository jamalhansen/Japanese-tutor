# Japanese Tutor (SRS)

A local-first Japanese Spaced Repetition System (SRS) for learning Hiragana, Katakana, and Kanji.

## Features
- **Progressive Learning**: Stages for Hiragana and Katakana unlocked by mastery.
- **SM-2 Algorithm**: Intelligent review scheduling (same as Anki).
- **LLM Mnemonics**: On-demand visual mnemonics generated by local AI (Ollama).
- **Web Interface**: Clean, fast, and local.

## Setup

1. Install dependencies:
   ```bash
   uv sync
   ```

2. Start the server:
   ```bash
   uv run japanese-tutor run
   ```
   Open `http://localhost:8421` in your browser.

## LLM Model Recommendations

This tool performs best with models that have strong Japanese language support.

### Recommended (Ollama)
- **`qwen2.5:7b`** (~4.7 GB): **Highly Recommended.** Best balance of Japanese accuracy and speed.
- **`qwen2.5:3b`** (~1.9 GB): Good alternative for machines with less RAM (8GB).
- **`phi4-mini`** (~2.3 GB): Fast and lightweight, used as default.

### Model Setup
```bash
ollama pull qwen2.5:7b
```

## Configuration
- `--port`: Change the server port (default: 8421).
- `--db-path`: Custom SQLite database path.
- `--provider`: LLM provider (`ollama`, `gemini`, `anthropic`).
- `--model`: Explicit model name or alias (`@best`, `@fast`).
